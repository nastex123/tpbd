# Data Fixtures

This directory stores authentic, documented historical data fixtures downloaded from upstream providers (NASA POWER, NASA AppEEARS, NOAA NCEI) to support:
1. Deterministic offline integration testing.
2. Hackathon demonstration mode without active internet connectivity.
3. Verification of statistical models against original provider records without synthetic hallucination.

Each fixture must preserve its origin metadata, parameter name, coordinate, temporal range, and download timestamp.
