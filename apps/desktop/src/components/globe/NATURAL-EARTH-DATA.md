Country boundaries in `countries-50m.json` are derived from Natural Earth’s Admin 0 Countries, 1:50m dataset (242 features).

Source: https://www.naturalearthdata.com/downloads/50m-cultural-vectors/ (download: https://naturalearth.s3.amazonaws.com/50m_cultural/ne_50m_admin_0_countries.zip)
Natural Earth data is in the public domain. Country names use the Spanish name field when available, with the dataset’s English administrative name as fallback. Boundary representation and country classification follow Natural Earth’s dataset.
